## P0 视觉与布局统一（Wave1-A，ui/ 全域）

1. **左侧图标导航栏**替代顶部 tabs（Umi 0.50 风格）：识别/批量/插件/设置 四项，
   当前项高亮，图标+文字，可折叠为纯图标；右侧内容区满宽
2. **设计系统 CSS 变量化**：间距/圆角/字号层级/主次按钮（primary/secondary/danger 三级，
   废除 area/win 杂色）/禁用/hover/focus 统一；深浅主题共用变量表
3. **设置页控件正确化**：主题/界面语言 → `<select>`；端口 → number 输入；
   热键 → 显示当前值 + 说明（Wayland 限制提示移到 tooltip）；顶部加"当前引擎"状态卡
   （native 就绪/插件名+状态），引擎切换入口
4. **窗口体验**：尺寸/位置记忆（settings 加 window 段，关闭时写，启动恢复）；
   应用图标（生成 256px SVG→png 设为窗口图标）；最小尺寸限制
5. **空状态与反馈**：批量页无文件/识别页无结果的空状态占位（图形+引导文案）；
   复制成功 → 行内"已复制✓"渐隐（替代全局 status 挤占）；按钮 loading 态
